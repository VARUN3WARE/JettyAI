    <div class="title">
        <h1 class="fs-40 c-dark fw-600">Tutorial: Web Scraping with Python Using Beautiful Soup</h1>
    </div>
    <div class="content-main fs-18 fw-400">
        <p class="rm">The internet is an absolutely massive source of data. Unfortunately, the vast majority if it isn't available in conveniently organized CSV files for download and analysis. If you want to capture data from many websites, you'll need to try web scraping.</p>
<p class="rm">Don't worry if you're still a total beginner — in this tutorial we're going to cover how to do web scraping with Python from scratch, starting with some answers to frequently-asked questions about web scraping. Then, we'll dig into some actual web scraping, focusing on weather data.</p>
<p class="rm"><img decoding="async" class="full-width jetpack-lazy-image jetpack-lazy-image--handled lazyload" src="data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAB4AAAAUAAQAAAACO9nKaAAAAAnRSTlMAAHaTzTgAAAFCSURBVHja7cEBDQAAAMKg909tDjegAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAIAXA7U8AAGRQ3nKAAAAAElFTkSuQmCC" data-lazy-loaded="1" scale="0" draggable="false" alt="nws" data-src="https://www.dataquest.io/wp-content/uploads/2020/09/web-scraping-weather.jpeg" data-eio-rwidth="2250" data-eio-rheight="1500"><noscript><img decoding="async" class="full-width jetpack-lazy-image jetpack-lazy-image--handled" src="https://www.dataquest.io/wp-content/uploads/2020/09/web-scraping-weather.jpeg" data-lazy-loaded="1" scale="0" draggable="false" alt="nws" data-eio="l"></noscript></p>
<p class="rm">If you're already familiar with the concept of web scraping, feel free to scroll past these questions and jump right into the tutorial!</p>
<h2>What is Web Scraping in Python?</h2>
<p class="rm">Some websites offer data sets that are downloadable in CSV format, or accessible via an <a href="https://en.wikipedia.org/wiki/Application_programming_interface" draggable="false">Application Programming Interface</a> (API). But many websites with useful data don't offer these convenient options.</p>
<p class="rm">Consider, for example, the National Weather Service's website. It contains up-to-date weather forecasts for every location in the US, but that weather data isn't accessible as a CSV or via API. It has to be viewed on the NWS site.</p>
<p class="rm"><img decoding="async" class="full-width jetpack-lazy-image jetpack-lazy-image--handled lazyload" src="data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAB4AAAARGAQAAAADxgJBfAAAAAnRSTlMAAHaTzTgAAAEVSURBVHja7cEBAQAAAIIg/69uSEABAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAADwYwYiAAHaKJJZAAAAAElFTkSuQmCC" data-lazy-loaded="1" scale="0" draggable="false" alt="nws" data-src="https://www.dataquest.io/wp-content/uploads/2019/01/nws.png" data-eio-rwidth="1994" data-eio-rheight="1136"><noscript><img decoding="async" class="full-width jetpack-lazy-image jetpack-lazy-image--handled" src="https://www.dataquest.io/wp-content/uploads/2019/01/nws.png" data-lazy-loaded="1" scale="0" draggable="false" alt="nws" data-eio="l"></noscript><noscript><img decoding="async" class="full-width" src="https://www.dataquest.io/wp-content/uploads/2019/01/nws.png"></noscript></p>
<p class="rm">If we wanted to analyze this data, or download it for use in some other app, we wouldn't want to painstakingly copy-paste everything. Web scraping is a technique that lets us use programming to do the heavy lifting. We'll write some code that looks at the NWS site, grabs just the data we want to work with, and outputs it in the format we need.</p>
<p class="rm">In this tutorial, we'll show you how to perform web scraping using <a href="https://www.python.org/downloads/release/python-350/" draggable="false">Python 3</a> and the <a href="https://www.crummy.com/software/BeautifulSoup/" draggable="false">Beautiful Soup</a> library. We'll be scraping weather forecasts from the <a href="https://www.weather.gov/" draggable="false">National Weather Service</a>, and then analyzing them using the <a href="https://pandas.pydata.org/" draggable="false">Pandas</a> library.</p>
<h2>How Does Web Scraping Work?</h2>
<p class="rm">When we scrape the web, we write code that sends a request to the server that's hosting the page we specified. Generally, our code downloads that page's source code, just as a browser would. But instead of displaying the page visually, it filters through the page looking for HTML elements we've specified, and extracting whatever content we've instructed it to extract.</p>
<p class="rm">For example, if we wanted to get all of the titles inside H2 tags from a website, we could write some code to do that. Our code would request the site's content from its server and download it. Then it would go through the page's HTML looking for the H2 tags. Whenever it found an H2 tag, it would copy whatever text is inside the tag, and output it in whatever format we specified.</p>
<p class="rm">One thing that's important to note: from a server's perspective, requesting a page via web scraping is the same as loading it in a web browser. When we use code to submit these requests, we might be "loading" pages much faster than a regular user, and thus quickly eating up the website owner's server resources.</p>
<h2>Why Python for Web Scraping?</h2>
<p class="rm">It's possible to do web scraping with many other programming languages. For example, we have <a href="https://www.dataquest.io/blog/web-scraping-in-r-rvest/">a tutorial on web scraping using R</a>, too.</p>
<p class="rm">However, using Python and the Beautiful Soup library is one of the most popular approaches to web scraping. That means there are lots of tutorials, how-to videos, and bits of example code out there to help you deepen your knowledge once you've mastered the Beautiful Soup basics.</p>
<p class="rm">We'll cover some other web scraping FAQs at the end of this article, but for now, it's time to dive into our web scraping project! And every web scraping project should begin with answering this question:</p>
<h2> Is Web Scraping Legal?</h2>
<p class="rm">Unfortunately, there's not a cut-and-dry answer here. Some websites explicitly allow web scraping. Others explicitly forbid it. Many websites don't offer any clear guidance one way or the other.</p>
<p class="rm">Before scraping any website, we should look for a terms and conditions page to see if there are explicit rules about scraping. If there are, we should follow them. If there are not, then it becomes more of a judgement call.</p>
<p class="rm">Remember, though, that <em>web scraping consumes server resources for the host website.</em> If we're just scraping one page once, that isn't going to cause a problem. But if our code is scraping 1,000 pages once every ten minutes, that could quickly get expensive for the website owner.</p>
<p class="rm">Thus, in addition to following any and all explicit rules about web scraping posted on the site, it's also a good idea to follow these best practices:</p>
<ul>
<li>Never scrape more frequently than you need to</li>
<li>Consider <a href="https://pypi.org/project/requests-cache/">caching</a> the content you scrape so that it's only downloaded once as you work on the code you're using to filter and analyze it, rather than re-downloading every time you run your code</li>
<li>Consider building pauses into your code using functions like <a href="https://docs.python.org/3/library/time.html"><code>time.sleep()</code></a> to keep from overwhelming servers with too many requests in too short a timespan.</li>
</ul>
<p class="rm">In our case for this tutorial, the NWS's data is public domain and <a href="https://www.weather.gov/disclaimer">its terms</a> do not forbid web scraping, so we're in the clear to proceed.</p>
<h2 id="thecomponentsofawebpage">The Components of a Web Page</h2>
<p class="rm">When we visit a web page, our web browser makes a request to a web server. This request is called a <code>GET</code> request, since we're getting files from the server. The server then sends back files that tell our browser how to render the page for us. The files fall into a few main types:</p>
<ul>
<li><a href="https://www.w3.org/TR/html/">HTML</a> — contain the main content of the page.</li>
<li><a href="https://developer.mozilla.org/en-US/docs/Web/CSS">CSS</a> — add styling to make the page look nicer.</li>
<li><a href="https://developer.mozilla.org/en-US/docs/Web/JavaScript">JS</a> — Javascript files add interactivity to web pages.</li>
<li>Images — image formats, such as <a href="https://en.wikipedia.org/wiki/JPEG">JPG</a> and <a href="https://en.wikipedia.org/wiki/Portable_Network_Graphics">PNG</a> allow web pages to show pictures.</li>
</ul>
<p class="rm">After our browser receives all the files, it renders the page and displays it to us. There's a lot that happens behind the scenes to render a page nicely, but we don't need to worry about most of it when we're web scraping. When we perform web scraping, we're interested in the main content of the web page, so we look at the HTML.</p>
<h2 id="html">HTML</h2>
<p class="rm"><a href="https://en.wikipedia.org/wiki/HTML">HyperText Markup Language</a> (HTML) is a language that web pages are created in. HTML isn't a programming language, like Python — instead, it's a markup language that tells a browser how to layout content. HTML allows you to do similar things to what you do in a word processor like Microsoft Word — make text bold, create paragraphs, and so on. Because HTML isn't a programming language, it isn't nearly as complex as Python.</p>
<p class="rm">Let's take a quick tour through HTML so we know enough to scrape effectively. HTML consists of elements called tags. The most basic tag is the <code>&lt;html&gt;</code> tag. This tag tells the web browser that everything inside of it is HTML. We can make a simple HTML document just using this tag:</p>
<pre class="language-html"><code class="language-html">&lt;html&gt;
&lt;/html&gt;</code></pre>
<p class="rm">We haven't added any content to our page yet, so if we viewed our HTML document in a web browser, we wouldn't see anything:</p>
<div style="border: 1px solid black;min-height: 25px;padding: 10px;margin-bottom:15px;margin-top:15px;"></div>
<p class="rm">Right inside an <code>html</code> tag, we put two other tags, the <code>head</code> tag, and the <code>body</code> tag. The main content of the web page goes into the <code>body</code> tag. The <code>head</code> tag contains data about the title of the page, and other information that generally isn't useful in web scraping:</p>
<pre class="language-html"><code class="language-html">&lt;html&gt;
&lt;head&gt;
&lt;/head&gt;
&lt;body&gt;
&lt;/body&gt;
&lt;/html&gt;
</code></pre>
<p class="rm">We still haven't added any content to our page (that goes inside the <code>body</code> tag), so we again won't see anything:</p>
<div style="border: 1px solid black;min-height: 25px;padding: 10px;margin-bottom:15px;margin-top:15px;"></div>
<p class="rm">You may have noticed above that we put the <code>head</code> and <code>body</code> tags inside the <code>html</code> tag. In HTML, tags are nested, and can go inside other tags.</p>
<p class="rm">We'll now add our first content to the page, in the form of the <code>p</code> tag. The <code>p</code> tag defines a paragraph, and any text inside the tag is shown as a separate paragraph:</p>
<pre class="language-html"><code class="language-html">&lt;html&gt;
&lt;head&gt;
&lt;/head&gt;
&lt;body&gt;
&lt;p&gt;
Here's a paragraph of text!
&lt;/p&gt;
&lt;p&gt;
Here's a second paragraph of text!
&lt;/p&gt;
&lt;/body&gt;
&lt;/html&gt;</code></pre>
<p class="rm">Here's how this will look:</p>
<div style="border: 1px solid black;min-height: 25px;padding: 10px;margin-bottom:15px;margin-top:15px;">
<p>Here's a paragraph of text!</p>
<p>Here's a second paragraph of text!</p>
</div>
<p class="rm">Tags have commonly used names that depend on their position in relation to other tags:</p>
<ul>
<li><code>child</code> — a child is a tag inside another tag. So the two <code>p</code> tags above are both children of the <code>body</code> tag.</li>
<li><code>parent</code> — a parent is the tag another tag is inside. Above, the <code>html</code> tag is the parent of the <code>body</code> tag.</li>
<li><code>sibiling</code> — a sibiling is a tag that is nested inside the same parent as another tag. For example, <code>head</code> and <code>body</code> are siblings, since they're both inside <code>html</code>. Both <code>p</code> tags are siblings, since they're both inside <code>body</code>.</li>
</ul>
<p class="rm">We can also add properties to HTML tags that change their behavior:</p>
<pre class="language-html"><code class="language-html">&lt;html&gt;
&lt;head&gt;
&lt;/head&gt;
&lt;body&gt;
&lt;p&gt;
Here's a paragraph of text!
&lt;a href="https://www.dataquest.io"&gt;Learn Data Science Online&lt;/a&gt;
&lt;/p&gt;
&lt;p&gt;
Here's a second paragraph of text!
&lt;a href="https://www.python.org"&gt;Python&lt;/a&gt; &lt;/p&gt;
&lt;/body&gt;&lt;/html&gt;</code></pre>
<p class="rm">Here's how this will look:</p>
<div style="border: 1px solid black;min-height: 25px;padding: 10px;margin-bottom:15px;margin-top:15px;">
<p>Here's a paragraph of text! <a href="https://www.dataquest.io">Learn Data Science Online</a></p>
<p>Here's a second paragraph of text! <a href="https://www.python.org">Python</a></p>
</div>
<p class="rm">In the above example, we added two <code>a</code> tags. <code>a</code> tags are links, and tell the browser to render a link to another web page. The <code>href</code> property of the tag determines where the link goes.</p>
<p class="rm"><code>a</code> and <code>p</code> are extremely common html tags. Here are a few others:</p>
<ul>
<li><code>div</code> — indicates a division, or area, of the page.</li>
<li><code>b</code> — bolds any text inside.</li>
<li><code>i</code> — italicizes any text inside.</li>
<li><code>table</code> — creates a table.</li>
<li><code>form</code> — creates an input form.</li>
</ul>
<p class="rm">For a full list of tags, look <a href="https://developer.mozilla.org/en-US/docs/Web/HTML/Element">here</a>.</p>
<p class="rm">Before we move into actual web scraping, let's learn about the <code>class</code> and <code>id</code> properties. These special properties give HTML elements names, and make them easier to interact with when we're scraping. One element can have multiple classes, and a class can be shared between elements. Each element can only have one id, and an id can only be used once on a page. Classes and ids are optional, and not all elements will have them.</p>
<p class="rm">We can add classes and ids to our example:</p>
<pre class="language-html"><code class="language-html">&lt;html&gt;
&lt;head&gt;
&lt;/head&gt;
&lt;body&gt;
&lt;p class="bold-paragraph"&gt;
Here's a paragraph of text!
&lt;a href="https://www.dataquest.io" id="learn-link"&gt;Learn Data Science Online&lt;/a&gt;
&lt;/p&gt;
&lt;p class="bold-paragraph extra-large"&gt;
Here's a second paragraph of text!
&lt;a href="https://www.python.org" class="extra-large"&gt;Python&lt;/a&gt;
&lt;/p&gt;
&lt;/body&gt;
&lt;/html&gt;</code></pre>
<p class="rm">Here's how this will look:</p>
<div style="border: 1px solid black;min-height: 25px;padding: 10px;margin-bottom:15px;margin-top:15px;">
<p class="bold-paragraph"> Here's a paragraph of text! <a href="https://www.dataquest.io" id="learn-link">Learn Data Science Online</a></p>
<p class="bold-paragraph extra-large"> Here's a second paragraph of text! <a href="https://www.python.org" class="extra-large">Python</a></p>
</div>
<p class="rm">As you can see, adding classes and ids doesn't change how the tags are rendered at all.</p>

There are several different types of requests we can make using <code>requests</code>, of which <code>GET</code> is just one. If you want to learn more, check out our <a href="https://www.dataquest.io/blog/python-api-tutorial/">API tutorial</a>.</p>
<p class="rm">Let's try downloading a simple sample website, <code>https://dataquestio.github.io/web-scraping-pages/simple.html</code>. We'll need to first download it using the <a href="https://2.python-requests.org/en/master/user/quickstart/#make-a-request">requests.get</a> method.</p>

<h2 id="parsingapagewithbeautifulsoup">Parsing a page with BeautifulSoup</h2>
<p class="rm">As you can see above, we now have downloaded an HTML document.</p>
<p class="rm">We can use the <a href="https://www.crummy.com/software/BeautifulSoup/">BeautifulSoup</a> library to parse this document, and extract the text from the <code>p</code> tag. We first have to import the library, and create an instance of the <code>BeautifulSoup</code> class to parse our document:</p>
<pre class="language-python"><code class="language-python">from bs4 import BeautifulSoup

soup = BeautifulSoup(page.content, 'html.parser')
</code></pre>
<p class="rm">We can now print out the HTML content of the page, formatted nicely, using the <code>prettify</code> method on the <code>BeautifulSoup</code> object:</p>
<pre class="language-python"><code>print(soup.prettify())</code></pre>
<pre class="language-html"><code class="language-html">&lt;!DOCTYPE html&gt;
&lt;html&gt;
&lt;head&gt;
&lt;title&gt;
A simple example page
&lt;/title&gt;
&lt;/head&gt;
&lt;body&gt;
&lt;p&gt;
Here is some simple content for this page.
&lt;/p&gt;
&lt;/body&gt;
&lt;/html&gt;</code></pre>
<p class="rm">As all the tags are nested, we can move through the structure one level at a time. We can first select all the elements at the top level of the page using the <code>children</code> property of <code>soup</code>. Note that <code>children</code> returns a list generator, so we need to call the <code>list</code> function on it:</p>
<pre class="language-python"><code>list(soup.children)</code></pre>
<pre class="language-text"><code>['html', 'n', &lt;html&gt; &lt;head&gt; &lt;title&gt;A simple example page&lt;/title&gt; &lt;/head&gt; &lt;body&gt; &lt;p&gt;Here is some simple content for this page.&lt;/p&gt; &lt;/body&gt; &lt;/html&gt;]</code></pre>
<p class="rm">The above tells us that there are two tags at the top level of the page -- the initial <code>&lt;!DOCTYPE html&gt;</code> tag, and the <code>&lt;html&gt;</code> tag. There is a newline character (<code>n</code>) in the list as well. Let's see what the type of each element in the list is:</p>
<pre class="language-python"><code>[type(item) for item in list(soup.children)]</code></pre>
<pre class="language-python"><code>[bs4.element.Doctype, bs4.element.NavigableString, bs4.element.Tag]</code></pre>
<p class="rm">As you can see, all of the items are <code>BeautifulSoup</code> objects. The first is a <code>Doctype</code> object, which contains information about the type of the document. The second is a <code>NavigableString</code>, which represents text found in the HTML document. The final item is a <code>Tag</code> object, which contains other nested tags. The most important object type, and the one we'll deal with most often, is the <code>Tag</code> object.</p>
<p class="rm">The <code>Tag</code> object allows us to navigate through an HTML document, and extract other tags and text. You can learn more about the various <code>BeautifulSoup</code> objects <a href="https://www.crummy.com/software/BeautifulSoup/bs4/doc/#kinds-of-objects">here</a>.</p>
<p class="rm">We can now select the <code>html</code> tag and its children by taking the third item in the list:</p>
<pre class="language-python"><code>html = list(soup.children)[2]</code></pre>
<p class="rm">Each item in the list returned by the <code>children</code> property is also a <code>BeautifulSoup</code> object, so we can also call the <code>children</code> method on <code>html</code>.</p>
<p class="rm">Now, we can find the children inside the <code>html</code> tag:</p>
<pre class="language-python"><code>list(html.children)</code></pre>
<pre class="language-text"><code>['n', &lt;head&gt; &lt;title&gt;A simple example page&lt;/title&gt; &lt;/head&gt;, 'n', &lt;body&gt; &lt;p&gt;Here is some simple content for this page.&lt;/p&gt; &lt;/body&gt;, 'n']</code></pre>
<p class="rm">As you can see above, there are two tags here, <code>head</code>, and <code>body</code>. We want to extract the text inside the <code>p</code> tag, so we'll dive into the body:</p>
<pre class="language-python"><code>body = list(html.children)[3]</code></pre>
<p class="rm">Now, we can get the <code>p</code> tag by finding the children of the body tag:</p>
<pre class="language-python"><code>list(body.children)</code></pre>
<pre class="language-text"><code>['n', &lt;p&gt;Here is some simple content for this page.&lt;/p&gt;, 'n']</code></pre>
<p class="rm">We can now isolate the p tag:</p>
<pre class="language-python"><code>p = list(body.children)[1]</code></pre>
<p class="rm">Once we've isolated the tag, we can use the <code>get_text</code> method to extract all of the text inside the tag:</p>
<pre class="language-python"><code>p.get_text()</code></pre>
<pre class="language-text"><code>'Here is some simple content for this page.'</code></pre>
<h2 id="findingallinstancesofatagatonce">Finding all instances of a tag at once</h2>
<p class="rm">What we did above was useful for figuring out how to navigate a page, but it took a lot of commands to do something fairly simple. If we want to extract a single tag, we can instead use the <code>find_all</code> method, which will find all the instances of a tag on a page.</p>
<pre class="language-python"><code class="language-python">soup = BeautifulSoup(page.content, 'html.parser')
soup.find_all('p')</code></pre>
<pre class="language-text"><code>[&lt;p&gt;Here is some simple content for this page.&lt;/p&gt;]</code></pre>
<p class="rm">Note that <code>find_all</code> returns a list, so we'll have to loop through, or use list indexing, it to extract text:</p>
<pre class="language-python"><code>soup.find_all('p')[0].get_text()</code></pre>
<pre class="language-text"><code>'Here is some simple content for this page.'</code></pre>
<p class="rm">If you instead only want to find the first instance of a tag, you can use the <code>find</code> method, which will return a single <code>BeautifulSoup</code> object:</p>
<pre class="language-python"><code>soup.find('p')</code></pre>
<pre class="language-text"><code>&lt;p&gt;Here is some simple content for this page.&lt;/p&gt;</code></pre>

<h2 id="usingcssselectors">Using CSS Selectors</h2>
<p class="rm">You can also search for items using <a href="https://developer.mozilla.org/en-US/docs/Web/Guide/CSS/Getting_started/Selectors">CSS selectors</a>. These selectors are how the CSS language allows developers to specify HTML tags to style. Here are some examples:</p>
<ul>
<li><code>p a</code> — finds all <code>a</code> tags inside of a <code>p</code> tag.</li>
<li><code>body p a</code> — finds all <code>a</code> tags inside of a <code>p</code> tag inside of a <code>body</code> tag.</li>
<li><code>html body</code> — finds all <code>body</code> tags inside of an <code>html</code> tag.</li>
<li><code>p.outer-text</code> — finds all <code>p</code> tags with a class of <code>outer-text</code>.</li>
<li><code>p#first</code> — finds all <code>p</code> tags with an id of <code>first</code>.</li>
<li><code>body p.outer-text</code> — finds any <code>p</code> tags with a class of <code>outer-text</code> inside of a <code>body</code> tag.</li>
</ul>
<p class="rm">You can learn more about CSS selectors <a href="https://developer.mozilla.org/en-US/docs/Web/Guide/CSS/Getting_started/Selectors">here</a>.</p>
<p class="rm"><code>BeautifulSoup</code> objects support searching a page via CSS selectors using the <code>select</code> method. We can use CSS selectors to find all the <code>p</code> tags in our page that are inside of a <code>div</code> like this:</p>
<pre class="language-python"><code>soup.select("div p")</code></pre>
<pre class="language-text"><code class="language-text">[&lt;p class="inner-text first-item" id="first"&gt;
First paragraph.
&lt;/p&gt;, &lt;p class="inner-text"&gt;
Second paragraph.
&lt;/p&gt;]</code></pre>
<p class="rm">Note that the <code>select</code> method above returns a list of <code>BeautifulSoup</code> objects, just like <code>find</code> and <code>find_all</code>.</p>

<p class="rm">We now know enough to download the page and start parsing it. In the below code, we:</p>
<ul>
<li>Download the web page containing the forecast.</li>
<li>Create a <code>BeautifulSoup</code> class to parse the page.</li>
<li>Find the <code>div</code> with id <code>seven-day-forecast</code>, and assign to <code>seven_day</code></li>
<li>Inside <code>seven_day</code>, find each individual forecast item.</li>
<li>Extract and print the first forecast item.</li>

<h2 id="extractinginformationfromthepage">Extracting information from the page</h2>
<p class="rm">As you can see, inside the forecast item <code>tonight</code> is all the information we want. There are <code>4</code> pieces of information we can extract:</p>
<ul>
<li>The name of the forecast item — in this case, <code>Tonight</code>.</li>
<li>The description of the conditions — this is stored in the <code>title</code> property of <code>img</code>.</li>
<li>A short description of the conditions — in this case, <code>Mostly Clear</code>.</li>
<li>The temperature low — in this case, <code>49</code> degrees.</li>
</ul>
<p class="rm">We'll extract the name of the forecast item, the short description, and the temperature first, since they're all similar:</p>
<pre class="language-python"><code class="language-python">period = tonight.find(class_="period-name").get_text()
short_desc = tonight.find(class_="short-desc").get_text()
temp = tonight.find(class_="temp").get_text()
print(period)
print(short_desc)
print(temp)</code></pre>
<pre class="language-text"><code class="language-text">Tonight
Mostly Clear
Low: 49 °F</code></pre>
<p class="rm">Now, we can extract the <code>title</code> attribute from the <code>img</code> tag. To do this, we just treat the <code>BeautifulSoup</code> object like a dictionary, and pass in the attribute we want as a key:</p>
<pre class="language-python"><code class="language-python">img = tonight.find("img")
desc = img['title']
print(desc)</code></pre>
<pre class="language-text"><code>Tonight: Mostly clear, with a low around 49. West northwest wind 12 to 17 mph decreasing to 6 to 11 mph after midnight. Winds could gust as high as 23 mph.</code></pre>
<h2 id="extractingalltheinformationfromthepage">Extracting all the information from the page</h2>
<p class="rm">Now that we know how to extract each individual piece of information, we can combine our knowledge with css selectors and list comprehensions to extract everything at once.</p>
<p class="rm">In the below code, we:</p>
<ul>
<li>Select all items with the class <code>period-name</code> inside an item with the class <code>tombstone-container</code> in <code>seven_day</code>.</li>
<li>Use a list comprehension to call the <code>get_text</code> method on each <code>BeautifulSoup</code> object.</li>
</ul>
<pre class="language-python"><code class="language-python">period_tags = seven_day.select(".tombstone-container .period-name")
periods = [pt.get_text() for pt in period_tags]
periods</code></pre>

<li>News articles</li>

<p class="rm">
<p class="rm">Still have questions? Let's take a look at some other web scraping FAQs:</p>
<h2>Why Web Scraping — When is this Needed?</h2>
<p class="rm">Web scraping is needed to unlock more powerful analysis when data isn't available in an organized format.</p>
<p class="rm">This could be useful for a variety of personal projects. You might, for example, want to scrape a sports website to analyze statistics associated with your favorite team.</p>
<p class="rm">But web scraping can also be important for data analysts and data scientists in a business context. There's an awful lot of data out on the web that simply isn't available unless you scrape it (or painstakingly copy it into a spreadsheet by hand for analysis). When that data might contain valuable insights for your company or your industry, you'll have to turn to web scraping.</p>
<h2>What Can I Do With Web Scraping?</h2>
<p class="rm">With web scraping, the biggest limitation is probably what you <em>may</em> do, not what you <em>can</em> do. With the right code, pretty much any data that's on a public-facing website <em>can</em> be downloaded, filtered, and formatted with web scraping.</p>
<p class="rm">Whether that's <em>allowed</em> or even <em>legal</em> is another story, though.</p>
<p class="rm">As we mentioned at the beginning of the article, it's important to determine a website's policy on web scraping before you attempt scraping it. If scraping is permitted, you should be sure to follow the best-practices outlined earlier in the article to make sure you aren't overly taxing the website in question.</p>
<h2>Python Libraries for Web Scraping</h2>
<ul>
<li><a href="https://pypi.org/project/requests/2.7.0/">requests</a> — this critical library is needed to actually get the data from the web server onto your machine, and it contains some additional cool features like caching too.</li>
<li><a href="https://pypi.org/project/beautifulsoup4/">Beautiful Soup 4</a> — This is the library we've used here, and it's designed to make filtering data based on HTML tags straightforward.</li>
<li><a href="https://lxml.de/index.html#introduction">lmxl</a> — An HTML and XML parser that's fast (and now, integrated with Beautiful Soup, too!)</li>
<li><a href="https://selenium-python.readthedocs.io/">Selenium</a> — A web driver tool that's useful when you need to get data from a website that the requests library can't access, because it's hidden behind things like login forms or mandatory mouse-clicks.</li>
<li><a href="https://scrapy.org/">Scrapy</a> — A full-on web scraping framework that might be overkill for one-off data analysis projects, but a good fit when scraping's required for production projects, pipelines, etc. If you're interested, we have a tutorial on <a href="https://www.dataquest.io/blog/web-scraping-with-scrapy/">Web Scraping with Scrapy</a> that includes 8 code examples to help get you started.</li>
<p>If you want to learn more about any of the topics covered here, check out our interactive courses which you can start for free: <a href="https://app.dataquest.io/course/apis-and-scraping">Web Scraping in Python</a></ul>
